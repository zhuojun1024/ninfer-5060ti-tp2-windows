KV cache quantization and context depth: fixed-text gold-standard comparison

Qwen3.8-27B-Coder390-EfficientThink-W4A4-W8A8-Vision · TP-2 --devices 0,1 · the scored text is fixed to the last 1024 tokens of the source stream · each run varies only "how much preceding context is visible"

Why this design can answer "does the model get worse as context grows"

The previous version ran one 257K natural stream end to end and looked at NLL token by token — depth and text content were locked together (deeper tokens belong to later books), so "the model degrades with context" could not be separated into depth versus text.

This version pins the scored text: the target block is always the last 1024 tokens of the source stream, and the K-th run exposes only the K tokens before it. For K ≥ 1 the text immediately preceding the target block is the same passage every time, so there is not even a concatenation seam, and the only variable is how far back the history can see. The x-axis is the actual history length of a token; at the same x position all arms score the same token, so both the between-arm difference and the between-depth difference are strictly paired.

Verified: the last 3000 characters of the 13 input streams are byte-identical (each is a character suffix of the source stream), so the 1008 scored tokens are strictly the same passage in every run.

The one remaining confounder: the content of the history changes with K — the source stream is four pg19 books concatenated in order, and when the visible window crosses a book boundary the preceding text becomes another book. So the "adjacent-depth paired difference" mixes "more history" and "different history" at the same time, and pointwise causality cannot be claimed; what can be claimed is the long-term trend.

Conclusion

Question 1: For the same passage, does the model get better or worse as history grows?

After pinning the scored text, all arms' NLL slope against visible history is negative: bf16 -0.168795 ± +0.032161 nats/decade (t=-5.25); int8 -0.109210 ± +0.021811 nats/decade (t=-5.01); fp8 -0.119033 ± +0.021986 nats/decade (t=-5.41); nvfp4 -0.119770 ± +0.023345 nats/decade (t=-5.13); k8v4 -0.116536 ± +0.022157 nats/decade (t=-5.26). Even the flattest one (int8) reaches t=-5.01, which means "the longer the history, the better this fixed passage is predicted" is statistically certain, in the opposite direction from "degradation with context".

Only 13 intervals of the adjacent-depth paired difference are positive (the passage becomes slightly harder as history grows); the largest is int8 at +0.008138 ± +0.005589 (t=+1.46) — indistinguishable from zero. All the rest are negative and most are significant.

So "the longer the context, the worse the model" does not hold for this model + this corpus. The previous version ran one 257K natural stream end to end and saw PPL rise at depth; that was caused by text content (deeper tokens belong to the later book), not by depth itself.

Note the shape of this curve: the gain from 0 to ~1K of history is extremely steep, then it flattens out; there is a large step at about 60,517 tokens (the purple line "book 02|03"), where the visible window first reaches the start of the book the target block belongs to. Lengthening the history further after that (including adding the completely unrelated books 01 and 00) never makes the result worse.

Question 2: Does the cost of KV quantization grow as the context lengthens?

Slope of the paired difference itself against history (positive = quantization cost grows with context):

  • bf16 − fp8: +0.005919 ± +0.007586 nats/decade (t=+0.78)
  • fp8 − bf16: -0.005919 ± +0.007586 nats/decade (t=-0.78)
  • int8 − bf16: +0.007940 ± +0.007351 nats/decade (t=+1.08)
  • int8 − fp8: +0.009823 ± +0.004649 nats/decade (t=+2.11)
  • k8v4 − bf16: -0.002792 ± +0.007226 nats/decade (t=-0.39)
  • k8v4 − fp8: +0.002498 ± +0.004798 nats/decade (t=+0.52)
  • nvfp4 − bf16: -0.006089 ± +0.008548 nats/decade (t=-0.71)
  • nvfp4 − fp8: +0.004786 ± +0.005693 nats/decade (t=+0.84)

Even when these slopes are positive they are only of order ~1e-3 nats/decade, while the absolute differences themselves are of order 1e-2 nats — the quantization cost is essentially a constant independent of context length, and there is no knee where "short context is lossless and long context collapses".
